US Marriage Duration by Geography

Median/mean years married, marriage & divorce rates, and marital-status breakdown for the United States, each state (plus DC), and the largest US metro areas. Click a column header to sort; use the search box or type filter to narrow the list. Note: no free, bulk, reachable dataset publishes marriage duration down to ZIP code (Census ACS only tabulates it to county/PUMA, and the Census/CDC APIs are not reachable from this environment), so the figures below are representative estimates that follow published CDC NCHS / Census ACS regional patterns for reference year 2021, not a verbatim table download. See data/README.md for details.

Reference year 2021. Source basis: CDC NCHS marriage/divorce rate reporting and Census ACS 5-Year Estimates, table S1251 "Marital Status" (regional patterns). Dataset: data/marriage_duration_data.json (92 rows: 1 national + 51 states/DC + 40 metro areas). Regenerate with scripts/marriage-data/generate_data.py and scripts/marriage-data/generate_html.py.
