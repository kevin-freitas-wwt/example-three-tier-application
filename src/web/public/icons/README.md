# App Icon Alternatives

Four SVG icon concepts for the AI-powered restaurant app. Each is a 512x512
square icon with rounded corners, suitable for use as a favicon, PWA icon, or
app store listing image.

| File | Concept |
|------|---------|
| `icon-cloche-spark.svg` | A serving cloche (dish cover) with an AI "spark" symbol above it, representing AI-assisted food service. |
| `icon-chef-hat-circuit.svg` | A chef's hat with circuit-board style lines and nodes, blending culinary and tech themes. |
| `icon-plate-chat.svg` | A plate and cutlery inside a chat bubble, representing an AI assistant/chatbot for dining. |
| `icon-fork-neural.svg` | A fork whose tines are connected like a neural network, symbolizing AI-driven menu/ordering intelligence. |

Pick one, or use them as starting points for further refinement in a design tool.
