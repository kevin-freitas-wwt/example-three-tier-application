# App Illustrations

Four larger scene illustrations matching the style and palette of the
`icon-cloche-spark.svg` app icon (serving cloche, AI "spark", warm
orange/red/cream colors). Each is a 400x300 landscape SVG meant for full
screen states in the web app, not as a small icon.

| File | Use for | What it shows |
|------|---------|----------------|
| `illustration-welcome.svg` | Welcome / onboarding screen | A cloche lid lifting off a plate, revealing food with steam, and an AI spark nearby — an inviting "let's get started" moment. |
| `illustration-empty-state.svg` | Empty list / no results screen | A bare plate with a dashed outline and a dim, idle spark — nothing has happened yet. |
| `illustration-success.svg` | Success / confirmation screen | A plate with a green checkmark badge, an open cloche lid, and celebratory sparks. |
| `illustration-error.svg` | Error / failure screen | A tipped-over cloche and spilled plate with a red warning badge. |

All four share the same table, plate, and cloche motifs as the app icon so
they read as one visual family. They are plain inline-friendly SVGs with no
external dependencies, so they can be used directly as `<img>` sources or
inlined as React components.
